# Syntheco — экосистема для GitHub Pages

Веб-приложение (чистый HTML/CSS/JS, без сборки) для публикации сайтов на GitHub Pages прямо из браузера.

## Возможности
- **🏠 Главная** — статистика проектов и лента действий.
- **📦 Проекты** — создание/удаление репозиториев, включение Pages в один клик.
- **🚀 Публикация** — загрузка файла → авто-создание репо → `.nojekyll` → включение Pages → ссылка `https://<логин>.github.io/<репо>/`.
- **✂️ Сниппеты** — gist через GitHub API.
- **🛠 Studio** (`/studio/`) — мини-конструктор сайтов с живым превью и кнопкой «Опубликовать».

## Безопасность
GitHub-токен (scope: `repo`, `workflow`, `gist`) хранится только в `localStorage` вашего браузера и отправляется напрямую в api.github.com. Никаких сторонних серверов.

## Запуск локально
Просто откройте `index.html` или поднимите сервер: `python3 -m http.server 8080`.

## Публикация этого проекта на GitHub Pages
1. Запушьте в репозиторий.
2. Settings → Pages → Source: **GitHub Actions** (workflow `.github/workflows/deploy.yml` соберёт статические файлы).
