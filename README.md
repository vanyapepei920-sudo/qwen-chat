# Really Visuals — демо-сайт продакшна видеографики

Лендинг в стиле [reallyvisuals.me](https://reallyvisuals.me): моушн-дизайн студия, тёмная неоновая тема, анимированный canvas-фон, генеративные превью кейсов.

## Стек
- Vite (vanilla JS)
- CSS custom properties, scroll-reveal, canvas-анимация

## Структура
```
index.html          — разметка и мета-теги
src/main.js         — рендер секций, анимации, интерактив
src/data.js         — данные проектов и услуг
src/style.css       — стили темы
public/favicon.svg  — иконка
```

## Запуск
```bash
npm install
npm run dev      # http://localhost:5173
npm run build    # прод-сборка в dist/
npm run preview  # предпросмотр сборки
```
