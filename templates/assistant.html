Подключение Gemini

  1. Зайди на aistudio.google.com → Get API key → Create API key.
  2. Скопируй ключ (формат AQ.…).
  3. В файл .env добавь: GEMINI_API_KEY=…
  4. Перезапусти сервер: Ctrl+C → python app.py.
